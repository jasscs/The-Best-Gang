# Barkada Bonding Invite 🐱💕

A cute, cat-themed invitation website for my barkada, built with plain HTML, CSS, and JavaScript.

## About

This is a simple one-page invitation made to invite my friends to our next bonding. It has a kawaii cat background, the event details, and a share button so the link can be sent easily to the group chat.

## Files

- `index.html` – the invitation content
- `style.css` – the cat-themed design
- `script.js` – the share button
- `assets/` – background and preview images
